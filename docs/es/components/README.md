# Componentes

Cada elemento viene ya registrado — no hay nada que instalar por componente.
Añade las dos etiquetas de [Instalación](/es/learn/installation) y cada etiqueta
de abajo funciona.

Cada página sigue la misma forma: primero un ejemplo en vivo, luego cuándo
usarlo y cuándo no, qué puede contener, los atributos que llevan una regla, las
custom properties de CSS que puedes sobrescribir, y notas de accesibilidad.
