# Componentes

Todo elemento já vem registrado — não há nada para instalar por componente.
Adicione as duas tags de [Instalação](/pt-br/learn/installation) e toda tag
abaixo funciona.

Cada página segue o mesmo formato: um exemplo ao vivo primeiro, depois quando
usar e quando não usar, o que ele pode conter, os atributos que carregam uma
regra, as custom properties de CSS que você pode sobrescrever, e notas de
acessibilidade.
