# Opacity

Variables that set the opacity level of an element. Defined in
`packages/pixel/tokens/opacity.css`.

| Token | Variable | Value |
|---|---|---|
| Semi Opaque | `--opacity-level-semiopaque` | 0.72 |
| Intense | `--opacity-level-intense` | 0.64 |
| Medium | `--opacity-level-medium` | 0.32 |
| Light | `--opacity-level-light` | 0.16 |
| Semi Transparent | `--opacity-level-semitransparent` | 0.08 |

Used for overlay states — a backdrop behind a modal, the `disabled` state
of a control, a subtle hover over a surface — never to hide legible text,
which is the job of color, not opacity.
