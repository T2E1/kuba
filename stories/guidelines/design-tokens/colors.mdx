# Colors

The tokens we swap for each brand or theme. Defined in
`packages/pixel/tokens/color.css`, with native CSS `light-dark()`
resolving the light/dark value of each token — see **Guidelines/Themes**
for how this ties into light/dark mode.

Each family has 5 tones — `lighter`, `light`, base, `dark`, `darker` —
except `master`, which has 7, and `menu`, which has 3.

## Pure

<Swatch token="pure-white" hex="#fff" />
<Swatch token="pure-black" hex="#000" />

The only two tokens with no `light-dark()` variation — they don't shift
with the theme, because they represent the absolute ends of the scale, not
a semantic color.
