# Design Tokens

Design Tokens are the style variables that sit between design and
technology: instead of a loose value (`24px`, `#6d5cae`) scattered through
the code, every visual decision gets a semantic name and a single source
of truth — `packages/pixel/tokens/`.

Each CSS file in that folder declares one group of tokens under `:root`,
and `packages/pixel/tokens/index.css` imports them all at once. Components
consume these tokens through `var(--token-name)` in each element's
`style.js` — never a hardcoded value.

## Groups

| Group | What it defines |
|---|---|
| **Typography** | Font size, line height, family, and weight. |
| **Border** | Border radius and width. |
| **Opacity** | Opacity levels for states and overlays. |
| **Shadows** | Shadow levels for depth. |
| **Spacing** | Composition spacing and inner spacing (`inset`). |
| **Colors** | Semantic palette, swappable per brand and per theme — see **Guidelines/Themes**. |

Each page below lists the group with the token name, its matching CSS
variable, and the current value.
