# Border

Defined in `packages/pixel/tokens/borderRadius.css` and `borderWidth.css`.

## Border radius

Variables that define the corners of shapes and elements.

| Token | Variable | Value |
|---|---|---|
| None | `--border-radius-none` | 0 |
| SM | `--border-radius-sm` | 8px |
| MD | `--border-radius-md` | 16px |
| LG | `--border-radius-lg` | 24px |
| Pill | `--border-radius-pill` | 500px |
| Circular | `--border-radius-circular` | 50% |

`Pill` is used for elements fully rounded at the ends (badges, tags);
`Circular` for perfectly round elements (avatars, icon action buttons).

## Border width

Variables used to specify the border thickness of elements.

| Token | Variable | Value |
|---|---|---|
| None | `--border-width-none` | 0 |
| Hairline | `--border-width-hairline` | 1px |
| Thin | `--border-width-thin` | 2px |
| Thick | `--border-width-thick` | 4px |
| Heavy | `--border-width-heavy` | 8px |
