# Typography

Typography carries hierarchy. Every piece of text in the interface should
use one of these tokens according to its importance — never a free-form
`font-size`. Defined in `packages/pixel/tokens/fontSize.css`,
`lineHeight.css`, `fontFamily.css`, and `fontWeight.css`.

## Font size

| Token | Variable | Value |
|---|---|---|
| XXXS | `--font-size-xxxs` | 12px |
| XXS | `--font-size-xxs` | 14px |
| XS | `--font-size-xs` | 16px |
| SM | `--font-size-sm` | 20px |
| MD | `--font-size-md` | 24px |
| LG | `--font-size-lg` | 32px |
| XL | `--font-size-xl` | 40px |
| XXL | `--font-size-xxl` | 48px |
| XXXL | `--font-size-xxxl` | 64px |
| Display | `--font-size-display` | 80px |
| Giant | `--font-size-giant` | 96px |

`<kb-text>`, `<kb-label>`, and `<kb-icon>` resolve their size against this
scale (`--font-size-{value}`) through the `size` attribute.

## Line height

| Token | Variable | Value |
|---|---|---|
| Default | `--line-height-default` | 100% |
| XS | `--line-height-xs` | 115% |
| SM | `--line-height-sm` | 120% |
| MD | `--line-height-md` | 133% |
| LG | `--line-height-lg` | 150% |
| XL | `--line-height-xl` | 170% |
| XXL | `--line-height-xxl` | 200% |

## Font family

| Token | Variable | Value |
|---|---|---|
| Base | `--font-family-base` | `"Roboto", sans-serif` |
| Highlight | `--font-family-highlight` | `"Roboto Condensed", sans-serif` |

`Base` is the default body-text family. `Highlight` is reserved for
headings and emphasis — swapping just these two tokens is enough to give a
brand a different typographic voice without touching a single component
(see **Guidelines/Themes**).

## Font weight

| Token | Variable | Value |
|---|---|---|
| Bold | `--font-weight-bold` | 700 |
| Medium | `--font-weight-medium` | 500 |
| Regular | `--font-weight-regular` | 400 |
