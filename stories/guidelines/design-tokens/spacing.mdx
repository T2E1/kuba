# Spacing

Defined in `packages/pixel/tokens/spacing.css`.

## Spacing

Spacing that standardizes composition and the vertical/horizontal rhythm
of components and interfaces.

| Token | Variable | Value |
|---|---|---|
| Quarck | `--spacing-quarck` | 4px |
| Nano | `--spacing-nano` | 8px |
| XXXS | `--spacing-xxxs` | 16px |
| XXS | `--spacing-xxs` | 24px |
| XS | `--spacing-xs` | 32px |
| SM | `--spacing-sm` | 40px |
| MD | `--spacing-md` | 48px |
| LG | `--spacing-lg` | 56px |
| XL | `--spacing-xl` | 64px |
| XXL | `--spacing-xxl` | 80px |
| XXXL | `--spacing-xxxl` | 120px |
| Huge | `--spacing-huge` | 160px |
| Giant | `--spacing-giant` | 200px |

## Inset

Inner spacing (`padding`) of a component where all four sides are exactly
equal.

| Token | Variable | Value |
|---|---|---|
| Quarck | `--spacing_inset-quarck` | 4px |
| Nano | `--spacing_inset-nano` | 8px |
| XS | `--spacing_inset-xs` | 16px |
| SM | `--spacing_inset-sm` | 24px |
| MD | `--spacing_inset-md` | 32px |
| LG | `--spacing_inset-lg` | 40px |
| Huge | `--spacing_inset-huge` | 48px |
| Giant | `--spacing_inset-giant` | 56px |

`Spacing` composes the space _between_ elements (margins, gaps). `Inset`
composes the space _inside_ an element (padding). Keeping the two scales
separate prevents an outer-spacing tweak from accidentally changing a
component's inner breathing room.
