# Border

Defined in `packages/pixel/tokens/borderRadius.css` and `borderWidth.css`.

## Border radius

The corners of shapes and elements.

| Token | Value | Sample |
|---|---|---|
| `--border-radius-none` | 0 | <span className="box" style={{borderRadius: 'var(--border-radius-none)'}}></span> |
| `--border-radius-sm` | 8px | <span className="box" style={{borderRadius: 'var(--border-radius-sm)'}}></span> |
| `--border-radius-md` | 16px | <span className="box" style={{borderRadius: 'var(--border-radius-md)'}}></span> |
| `--border-radius-lg` | 24px | <span className="box" style={{borderRadius: 'var(--border-radius-lg)'}}></span> |
| `--border-radius-pill` | 500px | <span className="box" style={{borderRadius: 'var(--border-radius-pill)'}}></span> |
| `--border-radius-circular` | 50% | <span className="box" style={{borderRadius: 'var(--border-radius-circular)', width: '2.5rem'}}></span> |

`pill` is for elements fully rounded at the ends — badges, tags, a
`width="fill"` call to action. `circular` is for perfectly round elements:
avatars, and the disc behind `<kb-fileupload>`'s icon.

?> `pill` is a large fixed length, not a keyword. On a box taller than 1000px
the corners stop looking like a pill — which is why it belongs on controls, not
on surfaces.

Where each is used by default: `sm` on buttons, inputs, covers and insets; `md`
on cards.

```html preview
<kb-stack direction="row" spacing="nano" align="center">
  <kb-button>Default (sm)</kb-button>
  <kb-button style="--button-border-radius: var(--border-radius-pill)">Pill</kb-button>
  <kb-button style="--button-border-radius: var(--border-radius-none)">Square</kb-button>
</kb-stack>
```

## Border width

Border thickness.

| Token | Value | Sample |
|---|---|---|
| `--border-width-none` | 0 | <span className="box box--bordered" style={{borderWidth: 'var(--border-width-none)'}}></span> |
| `--border-width-hairline` | 1px | <span className="box box--bordered" style={{borderWidth: 'var(--border-width-hairline)'}}></span> |
| `--border-width-thin` | 2px | <span className="box box--bordered" style={{borderWidth: 'var(--border-width-thin)'}}></span> |
| `--border-width-thick` | 4px | <span className="box box--bordered" style={{borderWidth: 'var(--border-width-thick)'}}></span> |
| `--border-width-heavy` | 8px | <span className="box box--bordered" style={{borderWidth: 'var(--border-width-heavy)'}}></span> |

`hairline` is the default for anything that borders a surface — inputs, outlined
cards, the fileupload target. `thin` is the button's border, so an outlined
button reads as a control rather than a container.
