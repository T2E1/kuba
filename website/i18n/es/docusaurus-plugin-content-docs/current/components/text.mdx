# Text

El elemento tipográfico de propósito general: tamaño, peso, color, familia,
interlínea y alineación son todos atributos mapeados a design tokens. No lleva
semántica de documento — no es un encabezado, un párrafo ni una lista, ni
siquiera cuando se estiliza como uno.

```html preview
<kb-stack direction="column" spacing="nano" align="start">
  <kb-text size="lg" weight="bold">Resumen mensual</kb-text>
  <kb-text size="xs">Todo lo que ocurrió en tu cuenta este mes.</kb-text>
  <kb-text size="xxxs" color="master">Actualizado hace 2 minutos</kb-text>
</kb-stack>
```

## Uso

```html
<kb-text size="xs" color="master-dark" weight="regular">Hola mundo</kb-text>
```

## Cuándo usarlo

- **Texto corrido y texto inline** en cualquier sitio, cuando deba seguir la
  escala tipográfica en vez de los valores por defecto del navegador.
- **Un título visual dentro de un componente** — un título de tarjeta, un título
  de sección — donde el tamaño y el peso importan y el esquema del documento no.
- **Texto que cambia por token** — un pie apagado, un total en negrita — sin
  escribir CSS por instancia.

## Cuándo no usarlo

- **Un encabezado de documento.** La navegación por encabezados de un lector de
  pantalla necesita un `<h1>`–`<h6>` real. Usa uno y estilízalo, o anida un
  `kb-text` dentro de él.
- **Una etiqueta o pista de campo** — `<kb-label>` y `<kb-helper>` existen para
  que el vocabulario de formulario siga siendo uniforme y se coloque solo.
- **Prosa larga con varios párrafos** — esto renderiza una caja inline sin
  espaciado entre párrafos; usa elementos `<p>` reales dentro de un
  `<kb-stack>`.

## Composición

- **Puede contener**: texto y markup inline — el shadow root es un único
  `<slot>` sin nombre. Un `<a>`, `<strong>` o un `<kb-icon>` anidados heredan el
  color y el tamaño definidos aquí.
- **Puede ser hijo de**: cualquier cosa. El host no tiene `display` propio, así
  que se comporta como contenido inline y participa en cualquier contexto flex o
  grid que lo rodee.

```html preview
<kb-text size="xs">
  Lee el <a href="#/es/learn/quick-start">inicio rápido</a> para verlo funcionando.
</kb-text>
```

## Tamaño

`size` recorre los escalones de la escala tipográfica compartida. Elige por el
papel, no por lo grande que se ve en un layout.

```html preview
<kb-stack direction="column" spacing="quarck" align="start">
  <kb-text size="xxxs">xxxs — pies de foto, metadatos</kb-text>
  <kb-text size="xxs">xxs — el valor por defecto</kb-text>
  <kb-text size="xs">xs — texto corrido</kb-text>
  <kb-text size="md">md — títulos de componente</kb-text>
  <kb-text size="xl">xl — títulos de página</kb-text>
</kb-stack>
```

| `size` | Se renderiza a | Úsalo para |
|---|---|---|
| `xxxs` / `xxs` | 12 / 14px | Pies de foto, metadatos, celdas densas. `xxs` es el valor por defecto. |
| `xs` / `sm` | 16 / 20px | Texto corrido y párrafos de entrada. |
| `md` / `lg` | 24 / 32px | Títulos de componente y de sección. |
| `xl`–`xxxl` | 40–64px | Títulos de página. |
| `display` / `giant` | 80 / 96px | Solo titulares de marketing — estos rompen las pantallas pequeñas. |

`weight` tiene tres escalones (`regular`, `medium`, `bold`) y `line-height` va
de `default` (100%) hasta `xxl` (200%). Las interlíneas más ajustadas encajan
con la tipografía grande de display; el texto corrido pide `lg` o `xl`.

## Color

`color` acepta cualquier sufijo de `--color-*`. Usa las familias semánticas para
el significado, y la rampa neutra `master-*` para la jerarquía.

```html preview
<kb-stack direction="column" spacing="quarck" align="start">
  <kb-text color="master-dark">master-dark — texto corrido</kb-text>
  <kb-text color="master">master — secundario</kb-text>
  <kb-text color="primary">primary — énfasis de marca</kb-text>
  <kb-text color="success">success — desenlace positivo</kb-text>
  <kb-text color="danger">danger — error o destructivo</kb-text>
</kb-stack>
```

Una palabra clave desconocida resuelve a una custom property indefinida y el
texto cae al color heredado en vez de fallar de forma visible — revisa el nombre
del token si un color "no se aplica".

## Atributos

| Atributo | Tipo | Por defecto | Descripción |
|---|---|---|---|
| `size` | escalón de token | `xxs` | Tamaño de la tipografía, resuelto contra `--font-size-\{valor\}`. |
| `weight` | `regular` \| `medium` \| `bold` | `regular` | Resuelto contra `--font-weight-\{valor\}`. |
| `color` | sufijo de token | `master-dark` | Resuelto contra `--color-\{valor\}`. |
| `family` | `base` \| `highlight` | `base` | Resuelto contra `--font-family-\{valor\}`. |
| `line-height` | escalón de token | `lg` | Resuelto contra `--line-height-\{valor\}`. |
| `align` | `left` \| `center` \| `right` \| `justify` | `left` | Alineación del texto. |

Este elemento no despacha eventos.

## Estilos

Los atributos cubren los casos por instancia. Las propiedades `--text-*` existen
para la sobrescritura a nivel de superficie — un panel entero desplazando su
tipografía — y para valores que la escala no expresa, como el espaciado entre
letras.

| Custom property | Por defecto | Controla |
|---|---|---|
| `--text-color` | `var(--color-\{color\})` | Color, sobrescribiendo el atributo. |
| `--text-font-family` | `var(--font-family-\{family\})` | Familia tipográfica. |
| `--text-font-size` | `var(--font-size-\{size\})` | Tamaño de la tipografía. |
| `--text-font-weight` | `var(--font-weight-\{weight\})` | Peso de la tipografía. |
| `--text-line-height` | `var(--line-height-\{lineHeight\})` | Interlínea. |
| `--text-letter-spacing` | `0.38px` | Espaciado entre letras — el único valor sin atributo. |

Prefiere el atributo para un elemento; recurre a la propiedad cuando una regla
deba aplicarse a muchos:

```css
.panel-dark kb-text {
  --text-color: var(--color-pure-white);
}
```

## Estados y accesibilidad

- El elemento no expone ningún rol. Estilizarlo al tamaño `display` no lo
  convierte en un encabezado — combínalo con un elemento de encabezado real, o
  con `role="heading"` más `aria-level`, cuando introduce una sección.
- Vigila el contraste al bajar por la rampa `master-*`: `master-light` sobre
  blanco es de grado decorativo, no de texto corrido.
- No dejes que el color sea el único portador del significado — un total
  coloreado con `danger` necesita palabras que digan qué va mal.
- `align="justify"` produce un espaciado irregular entre palabras en columnas
  estrechas; resérvalo para medidas anchas.

## Recomendado y no recomendado

| Haz | No hagas |
|---|---|
| Elegir el `size` por el papel del texto | Elegirlo por lo grande que se ve en un layout |
| Envolver o anidar un elemento de encabezado real para la estructura | Usar `size="xxxl"` y llamarlo encabezado |
| Usar `<kb-label>` / `<kb-helper>` dentro de campos de formulario | Recrearlos con `kb-text` y atributos por instancia |
| Establecer `--text-*` en un ancestro para desplazar toda una superficie | Repetir la misma sobrescritura de atributo en cada elemento |
