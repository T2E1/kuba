# Website

This website is built using [VitePress](https://vitepress.dev/), a Vite-native static site generator.

## Installation

```bash
npm install
```

**Note**: feel free to use the package manager of your choice.

## Local Development

```bash
npm run dev
```

This command starts a local development server at `http://localhost:5173`. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Preview

```bash
npm run preview
```

Serves the built `build` directory locally, the same way it will be served in production — use this to check a build before it ships.
